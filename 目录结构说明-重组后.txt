【双模式启动路径（重组后直接能用）】
------------------------------------------------------------
▶ 模式A：前后端分离部署（推荐日常开发用）

   后端：
     cd f:\docker\xindong-station\backend
     mvn spring-boot:run
     （默认分离模式：只启后端接口，不拷贝前端，端口 8080）

   前端：
     cd f:\docker\xindong-station\frontend\xindong-web
     npm run dev
     （Vite 独立启动，.env.production 里的
      VITE_API_BASE=http://localhost:8080/api/v1 已生效）

------------------------------------------------------------
▶ 模式B：合包部署（单 jar 包含前后端，同端口，上线用）

   ① 前端先构建：
      cd f:\docker\xindong-station\frontend\xindong-web
      npm run build

   ② 后端打包（激活 embed-frontend 合包模式）：
      cd f:\docker\xindong-station\backend
      mvn clean package -Pembed-frontend -DskipTests
      【pom.xml 里的路径脚本已自动改好：
       原 ${project.basedir}/web/dist
       → 新 ${project.basedir}/../frontend/xindong-web/dist】

   ③ 启动 jar（激活 embed-frontend Spring Profile）：
      java -jar target\xindong-station-*.jar --spring.profiles.active=embed-frontend

   ④ 访问：http://localhost:8080/
      前端页面 + 后端接口同端口，单 jar 直接部署

【后续新增文件放哪？】
