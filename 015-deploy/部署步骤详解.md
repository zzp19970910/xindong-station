============================================================
 第一阶段：前置准备（约1-3天，主要等备案）
============================================================

1. 【买云服务器】
   · 阿里云/腾讯云/华为云任意一家，新人价30-60元/年
   · 配置：1核 vCPU + 2GB 内存 + 40GB SSD 系统盘 足够
   · 操作系统：Ubuntu 22.04 LTS 64位（切记别选Windows Server）
   · 地域：选离你/你用户最近的（国内用户选国内节点，延迟最低）

2. 【买域名】（可选，但强烈推荐，比记IP方便N倍）
   · 阿里云万网/腾讯云Namesilo都行，.com/.cn后缀几块钱/年
   · 注意：国内买的域名才能在国内服务器备案

3. 【ICP备案】（国内服务器强制，不然域名解析了也打不开）
   · 云服务器控制台 → 搜索"备案" → 按流程上传身份证+人脸核验+填真实信息
   · 一般 1-3 个工作日通过，通过后域名才能正常解析

4. 【域名解析】（备案通过后操作）
   · 云控制台 → DNS解析 → 添加两条记录：
      - 主机记录 @  → 记录类型 A → 记录值 你的服务器公网IP
      - 主机记录 www → 记录类型 A → 记录值 你的服务器公网IP
   · 生效时间：一般10分钟内

5. 【服务器安全组/防火墙放行端口】（非常重要！不然外面访问不到）
   · 云控制台 → 实例 → 安全组 → 入方向放行 3 个端口：
      - 22  TCP  SSH远程登录（只放行你自己的公网IP更安全）
      - 80  TCP  HTTP（必开，证书申请+跳转用）
      - 443 TCP  HTTPS（必开，正式访问入口）
   · 其他端口（8080/5173/3306/6379等）一律不要开，内部Docker网络通就行

============================================================
 第二阶段：服务器初始化（只需一次，SSH登录后执行）
============================================================

用Xshell/Putty/VSCode Remote SSH 登录你的服务器：
  ssh root@你的服务器公网IP

然后逐行执行：

---
# 1. 系统更新 + 基础工具安装
apt update && apt upgrade -y
apt install -y curl wget git vim ufw fail2ban

# 2. 开启系统防火墙（安全组开了系统层也要开，双层防护）
ufw default deny incoming
ufw default allow outgoing
ufw allow 22/tcp
ufw allow 80/tcp
ufw allow 443/tcp
ufw --force enable

# 3. 安装 Docker + Docker Compose 官方版（Ubuntu一键脚本最省事）
curl -fsSL https://get.docker.com | bash
# 安装完验证：
docker --version          # 应有输出，比如 27.x.x
docker compose version    # 应有输出，比如 v2.x.x

# 4. 创建部署目录
mkdir -p /opt/xindong-station && cd /opt/xindong-station
---

============================================================
 第三阶段：上传代码 + 改3处必须改的配置
============================================================

方式A（推荐用Git，最方便后续更新代码）：
  把项目推到GitHub/Gitee私有仓库，服务器上 git clone

方式B（不用Git，直接传文件）：
  用 WinSCP / FileZilla / VSCode SFTP 插件，
  把本地 f:\docker\xindong-station\ 整个项目目录上传到服务器 /opt/xindong-station/
  （只传：Dockerfile + 015-deploy/ + backend/ + frontend/ 这4个就行，不用传 node_modules/target/.idea）

上传完成后，改3处必须改的地方（很重要，别用默认值）：

---
# 【必须改1】docker-compose.yml 里的 JWT_SECRET 和 LETTER_AES_KEY
#    改成两个不同的随机32+位字符串（比如打开密码管理器生成，或者键盘瞎打）
vim /opt/xindong-station/015-deploy/docker-compose.yml
#    找到 JWT_SECRET: 和 LETTER_AES_KEY: 两行，替换默认值

# 【必须改2】nginx.conf 里所有的 your-domain.com 改成你自己的域名
#    全局替换：:%s/your-domain.com/你真实的域名.com/g
vim /opt/xindong-station/015-deploy/nginx.conf

# 【必须改3】docker-compose.yml 里certbot服务的邮箱和域名
#    找到 -m your-email@example.com -d your-domain.com -d www.your-domain.com
#    改成：你的真实邮箱 -d 你的域名.com -d www.你的域名.com  （没有www就去掉那行）
vim /opt/xindong-station/015-deploy/docker-compose.yml
---

============================================================
 第四阶段：启动部署（复制粘贴两行就行）
============================================================

cd /opt/xindong-station/015-deploy

# Step 1: 构建镜像 + 后台启动（第一次构建比较慢，约5-15分钟，耐心等）
docker compose up -d --build

# Step 2: 看启动日志有没有报错
docker compose logs -f app
# 看到 Started XxxApplication in X.XXX seconds + 没红色报错 = 启动成功
# 按 Ctrl+C 退出日志查看（程序继续后台跑）

# Step 3: 检查所有容器状态（应该全是 healthy / Up）
docker compose ps

============================================================
 第五阶段：验证部署成功
============================================================

在自己电脑浏览器打开：
  HTTP： http://你的域名.com       → 应该自动跳转到 https://
  HTTPS：https://你的域名.com      → 看到心动空间站登录页 ✅

按之前的三步联通验证走一遍：
  1. 注册两个情侣账号 / 或者用测试验证码 1234 登录
  2. 登录后点 心情/日记/恋爱清单 页面
  3. 数据正常加载不报错 = 公网部署100%成功！🎉

============================================================
 【附】常用运维命令（部署完日常维护用）
============================================================

# 查看实时日志
cd /opt/xindong-station/015-deploy
docker compose logs -f app        # 后端应用日志

cd /opt/xindong-station
git pull                           # 如果用Git的话
cd 015-deploy
docker compose up -d --build       # 重新构建+重启，约3-5分钟

# 停止所有服务（不删除数据）
docker compose stop

# 停止+删除容器（数据还在./data和./logs里，不会丢）
docker compose down

# 完整备份：把整个 /opt/xindong-station/015-deploy 目录打包，就是完整备份（含数据库+日志+配置）
tar -czf xindong-backup-$(date +%Y%m%d).tar.gz /opt/xindong-station/015-deploy/

# SQLite数据库每日自动备份（建议加crontab）
# crontab -e 加一行：0 3 * * * cp /opt/xindong-station/015-deploy/data/xindong_dev.db /opt/xindong-station/015-deploy/data/backup-$(date +\%Y\%m\%d).db
# 效果：每天凌晨3点自动备份一次数据库，保留最近N天就行
